③ 内网穿透链路（设备为客户端）

1
远端 MCP 客户端
Streamable HTTP · https://n.huziyang.top/mcp/<device> · Bearer clientToken
▼ HTTPS
2
Node.js 穿透服务端（公网 VPS）
鉴权 device+tunnelToken/clientToken → 校验设备在线 → 生成转发请求；10s WS ping / 3 次丢包（≈35s）判死；设备级质量指标（RTT / 重连 / 流量 / 失败）
▼ WebSocket 隧道
3
设备端 mcpd tunnel（客户端）
收到 request → 注入本地 Bearer Token → 转发 127.0.0.1:9123/mcp；拒绝 /api/* 控制面；运行态落盘 tunnel.runtime.json
▼ HTTP 回环
4
本地 MCP 服务执行工具
响应原路回传：小响应单帧，>256KB / GET 长流按 64KB 分帧（头帧 + chunk + 结束帧）

④ 安全边界

✓ 默认仅本机bind=127.0.0.1，不暴露局域网/公网
✓ 非回环强制鉴权监听 0.0.0.0 时无 Token 直接拒绝启动
✓ Token 鉴权48 位随机 Token，WebUI 一键轮换
✓ 只读模式read_only=true 禁用命令执行与写文件
✓ 命令允许列表allowlist 非空时仅放行指定命令前缀
✓ 控制面隔离隧道仅转发 /mcp /sse /health；/api/* 及路径穿越写法一律拒绝
✓ 非回环强制鉴权bind 非回环且无 Token 时拒绝启动
⚠ 隧道暴露公网双 Token（tunnelToken/clientToken）须妥善保管，泄露立即更换
